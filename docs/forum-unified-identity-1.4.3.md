# Unified Identity & Access Management (Forum 1.4.3)

Use `/admin/#/identity` and select a local account (search by email, name or UUID). The account card shows local MFA status, effective RBAC scopes for a fresh local login (not token scopes), current managed forum roles, browser sessions and system role choices. The ACL inspector resolves a category or board UUID through the existing permission resolver, including inheritance and publication state. Existing group, delegation and member APIs are called directly. No second identity or ACL store is introduced.

System role changes require a global admin HTTPS browser session, CSRF, recent authentication (local password and TOTP if enabled, or SkiF4er ID MFA), exact target UUID and a SHA-256 access snapshot revision. Managed forum groups and delegated roles are preserved; use their dedicated editors. Wildcard role assignment, protected administrator accounts, erased accounts and self-editing are refused through this card. Existing administrator recovery and role definition management are separate. A successful system role change revokes browser sessions and records before/after role handles in SQL audit. API tokens remain subject to live permission intersection. Group and delegation changes use existing live authorization checks; the local browser session may need a new login to receive newly granted scopes.

The existing session API remains SkiF4er-only by default; `provider=all` on list/single revoke and `provider: "all"` on revoke-all selects local, legacy and SkiF4er sessions. Revocation affects local forum/core access, not remote Keycloak sessions or API tokens. The interface shows local MFA configuration, not the remote IdP enrollment state; remote MFA remains managed in SkiF4er ID. No reset or bypass of another user's MFA is introduced.

No schema migration. Deploy over 1.4.2 with synchronized ACP assets and restart PHP processes. Run the multi-database acceptance test and browser regression in CI before production. Confirm IdP step-up in staging with a real MFA-enabled account.
