## Пространство для вашего сообщества

CajeerEngine Forum Edition — self-hosted форум от CajeerTeam на базе CajeerEngine. Платформа объединяет публичные обсуждения, управление участниками, модерацию, миграцию со сторонних форумов, аналитику и AI-инструменты в одной установке. Данные и инфраструктура находятся под контролем владельца сайта; внешние интеграции настраиваются отдельно.

| Область | Возможности |
| --- | --- |
| Сообщество | Категории, разделы, темы, ответы, реакции, подписки, профили, личные переписки, вложения и опросы |
| Безопасность | Роли, ACL, сессии, MFA, ограничения запросов, жалобы, санкции и апелляции |
| Администрирование | Единый ACP, настройки, интеграции, очереди, журнал операций и поддержка пользователей |
| Поиск и SEO | Поиск обсуждений, серверный HTML, sitemap, RSS, перенаправления при миграции |
| Миграция | Импорт phpBB, XenForo и Invision Community с проверками и ограничениями конкретного источника |
| Аналитика | Встроенные события, агрегаты, вовлечённость, удержание, GA4 и Яндекс Метрика |
| AI | Чат, помощь в темах и поиске, написание текста, поддержка и рекомендации модерации через настроенный OpenAI |
| Эксплуатация | Резервное копирование, мониторинг, управляемые фоновые задачи, подписанные обновления и восстановление |

[Подробнее о возможностях и ограничениях →](docs/forum-product.md)

## Актуальный релиз · 1.6.0

**GitHub Automated Updates Stable** — завершение реализации контура автоматизированных обновлений: от обнаружения релиза до проверяемой установки, восстановления и допуска к публикации.

- Автономная установка подписанных пакетов по явно разрешённой политике хоста.
- Проверка точного артефакта, доверия к издателю, резервной копии и восстановления до замены файлов.
- Двухэтапная публикация: независимая квалификация до публикации и проверка реального обновления из GitHub до назначения `Latest`.

> [!IMPORTANT]
> `1.6.0` — версия исходного дерева, а `stable` — объявленный канал. Это **не подтверждение фактически пройденной production-сертификации**. В поставленном архиве нет доказательств успешного прохождения всех внешних ворот. Перед публикацией или развёртыванием необходима [релизная приёмка](docs/forum-github-updates-stable-1.6.0.md). Обнаружено также расхождение файла `VERSION` и метаданных ядра; см. [замечание к исходному архиву](docs/releases/1.6.0.md#проверка-идентичности-сборки).

## Быстрый старт

Для локального ознакомления из исходников требуются PHP и Composer, расширения PHP и PDO SQLite. Выполняйте в корне отдельной тестовой копии:

```bash
composer install --no-interaction
php bin/cajeer install --sqlite --interactive
php -S 127.0.0.1:8080 -t public
```

Откройте <http://127.0.0.1:8080/>. Административная панель — `/admin/`.

Для production используйте проверенный полный подписанный dist, PHP-FPM, HTTPS и document root `public/`. Встроенный PHP-сервер предназначен исключительно для разработки. [Полное руководство по установке](docs/forum-installation.md).

## Системные требования

| Компонент | Требование или профиль |
| --- | --- |
| PHP | `>=8.4.1 <9.0` |
| Зависимости | Composer 2, расширения согласно `composer.json`, PDO-драйвер выбранной БД |
| Основная БД | PostgreSQL 17+, рекомендуется 18+ |
| Локальный профиль | SQLite 3.40+ |
| Альтернативные БД | MySQL 8.4+, MariaDB 10.11+; отдельная проверка совместимости и восстановления |
| Production | Linux, PHP-FPM, Nginx/HTTPS; отдельный оператор обновлений при автономном режиме |

## Разработка и проверка

```bash
php bin/cajeer api:lint --strict --json
php tools/generate-api-sdk.php --check
php tools/forum-regression.php
node --check public/forum-assets/forum.js
```

Команды требуют установленного окружения и зависимостей; запускайте интеграционные тесты на изолированных БД. Полную матрицу определяет [forum-ci.yml](.github/workflows/forum-ci.yml). Локальные проверки не заменяют внешний CI и физическую приёмку.
